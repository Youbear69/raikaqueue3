วิธีใช้งาน
  • คลิก = เลือกรูป, Ctrl+คลิก = เลือกเพิ่ม/เอาออก, Shift+คลิก = เลือกช่วง, Ctrl+A = เลือกทั้งหมด, Esc = ยกเลิก
  • ดับเบิลคลิกรูป = ดูเต็มจอ, ดับเบิลคลิกโฟลเดอร์ = เปิดโฟลเดอร์
  • คลิกที่ชื่อ = เปลี่ยนชื่อ (Enter บันทึก, Esc ยกเลิก)
  • ลากรูปวางบนโฟลเดอร์ = ย้ายเข้า, ลากวางบนปุ่ม ← = ย้ายออกจากโฟลเดอร์ (ลากรูปที่เลือกไว้ = ย้ายทั้งชุด)
  • ลากไฟล์รูปจากเครื่องมาวางบนหน้า/บนโฟลเดอร์ = อัพโหลด (เลือกหลายไฟล์ได้)
  • ปุ่ม "ก็อป URL" (hover บนรูป) เอาลิงก์ไปวางช่องรูปได้ทุกที่ในหน้า ตั้งค่า
  • อัพรูป/สร้างโฟลเดอร์ในแอป Google Drive (โฟลเดอร์ raika-img-uploads) ก็แสดงที่นี่เหมือนกัน
